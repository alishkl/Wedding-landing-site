# Қыз ұзату — сайт-приглашение (React + TypeScript + Vite)

## Запуск на Windows
1. Установите Node.js LTS (nodejs.org). 2. Распакуйте архив (проект — папка, где лежит `package.json`).
3. Откройте эту папку в терминале. 4. `npm install` 5. `npm run dev` 6. Откройте адрес из терминала (обычно http://localhost:5173).
Сборка для публикации: `npm run build` → папка `dist`.

## Что менять — `src/config.ts`
Имя (`bride` и родительный падеж `brideGen`), родители/хозяева (`hosts`), дата с часовым поясом (`eventISO`), город, адрес, зал, координаты (`lat`/`lng` — по ним строятся ссылки 2GIS и Google Maps), тексты, программа, контакты, варианты ответа RSVP. Календарь, день недели и таймер считаются из `eventISO` автоматически. Цвета — переменные в начале `src/styles.css`.

## Фото и музыка
Все картинки лежат в `public/images/` и подключены в `config.photos`: `hero` — первый экран (без тонирования), `bg1` — экран «Құрметті», `bg2` — экран с приглашением и таймером, `bg3` — календарь (белое полотно), `bg4` — фон экранов «Той иелері» и «Сауалнама», `bg5` — экран «Мекен», `bg6` — экран «Программа», `flowers` — PNG с цветами для тонкой линии между экранами и нижнего ряда на первом экране. Заменяйте файлы с теми же именами (желательно вертикальные, около 9:16). Музыка: положите `kazakh-instrumental.mp3` в `public/music/` (только файл с разрешённым использованием).

## RSVP через Google Forms → Google Sheets
1. forms.google.com → форма с двумя вопросами: «Имя» (короткий ответ) и «Присутствие» (короткий ответ — туда придёт текст выбранного варианта из `config.rsvp.options`).
2. Вкладка «Ответы» → значок Google Таблиц → создать таблицу.
3. Меню ⋮ → «Получить предварительно заполненную ссылку» → заполните тестовыми значениями → «Получить ссылку». В ссылке есть `entry.123456789=…` — это ID полей.
4. В обычной ссылке формы `https://docs.google.com/forms/d/e/<FORM_ID>/viewform` скопируйте `<FORM_ID>`.
5. Впишите `formId` и `entries.name` / `entries.attending` (вида `entry.123456789`) в `config.rsvp`.
Браузер отправляет данные в режиме `no-cors` и не может подтвердить сохранение, поэтому сайт пишет «ответ отправлен через форму», а не «сохранён». После настройки отправьте тестовый ответ и проверьте таблицу. Пока `formId` пуст, форма честно сообщает, что отправка не настроена.
